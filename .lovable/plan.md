
# Portfolio Website for Yuvaraj D

## Overview
Build a modern, dark-themed personal portfolio website as a single-page React application with smooth scrolling, animations, and a professional design using the uploaded HTML as reference.

## Sections & Features

### 1. Navbar
- Fixed top navbar with logo "YD."
- Links: Home, About, Skills, Projects, Services, Contact
- Mobile hamburger menu
- Active link highlighting on scroll

### 2. Hero Section
- Large name display: "Yuvaraj D."
- Subtitle: "Freelance Web Developer"
- Tagline about crafting pixel-perfect experiences
- "Available for Work" badge
- Two CTA buttons: "View My Work" and "Contact Me"
- Animated code card decoration (from uploaded HTML)
- Scroll indicator

### 3. About Me
- Short bio paragraph about being a passionate web developer
- Profile image placeholder
- Key stats/highlights
- Skills mention: HTML, CSS, JavaScript, React

### 4. Skills Section
- Visual skill cards with icons and progress indicators
- Skills: HTML, CSS, JavaScript, Git & GitHub
- Animated progress bars or percentage displays

### 5. Projects Section
- Card grid with 3 projects:
  - **Desi Agro Guide** — Agriculture guidance app (HTML/CSS/JS) → https://desi-agro-guide.lovable.app/
  - **Offline Chessmate Game** — Offline chess game (JS) → https://offline-chessmate.lovable.app + Amazon link
  - **Portfolio Website** — This portfolio (HTML/CSS/JS) → placeholder
- Each card: title, description, tech tags, "Live Demo" + "View Code" buttons

### 6. Services Section
- 4 service cards: Website Development, Landing Page Design, Bug Fixing, Website Redesign
- Icons and brief descriptions for each

### 7. Contact Section
- Contact form: Name, Email, Message fields with submit button
- Email: yuvaraj@example.com
- Social links: GitHub, LinkedIn (placeholder URLs)

### 8. Footer
- "© 2026 Yuvaraj D. All rights reserved."

## Design
- **Theme**: Dark background with accent color highlights (matching uploaded design)
- **Fonts**: Syne (headings) + DM Sans (body) from Google Fonts
- **Animations**: Fade-in on scroll, hover effects on cards/buttons, smooth section transitions
- **Responsive**: Mobile-first with breakpoints for tablet and desktop
